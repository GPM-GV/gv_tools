Process Parsivel#

process_parsivel 1.2.1 is bundled with GV Tools 0.40.0. The bundled copy supports APU and PIERS archives, location timelines, daily processing, NetCDF output, radar-band reflectivity, and parameter/DSD plotting. A separate process-parsivel installation is not required.

Process a single ZIP/CSV/DAT file or a recursively scanned directory.

Directory inputs select files containing YYYYMMDD in their filename. A single file is filtered by timestamps inside that file, so it may contain records from more than one day.

process_parsivel.run(input_path, instrument, *, start_date=None, end_date=None, output_dir=None, table_dir=None, temp_dir=None, radar_bands=None, water_temperature=20.0, permittivity_model='Liebe1991', radar_frequencies=None, minimum_dbz=None)[source]#

Process one file or directory without reading command-line arguments.

Parameters use regular Python values and are safe for Jupyter. Dates may be strings ("2023-01-01"), date/datetime objects, or pandas timestamps. If start_date is omitted, dates are inferred from filenames.

Returns a dictionary keyed by YYYY-MM-DD. Each value contains the (parameters, psd, moments) DataFrame tuple. Empty days are omitted.

Convert hourly ZIP archives into one derived Xarray/NetCDF file per day.

ZIP archives are only read. Their CSV/DAT members are extracted beneath a temporary work directory and removed after every day, including on errors. start_date and end_date are inclusive when supplied.

process_parsivel.plot_parameters(parms, columns=None, *, accumulate=False, accumulation_labels=None, title=None, figsize=None, primary_color='tab:blue', accumulation_color='tab:red', grid=True, save_path=None, dpi=150, show=True)[source]#

Plot parameter time series with optional cumulative values on y2 axes.

accumulate=True accumulates Rain. Pass a column name or iterable, such as accumulate=["Rain", "Total Drops"], to select other plotted parameters. Accumulations use pandas cumsum() and ignore missing values by default. The function returns (figure, primary_axes, secondary_axes); secondary_axes is a dictionary keyed by accumulated column name.

Plot a DSD time series with contours or bin-faithful colored cells.

The layout follows the supplied plot_dsd.py function. Values less than or equal to zero are masked before logarithmic normalization. If the entire selected DSD is dry, the axes are returned with a clear annotation instead of raising a log-scale warning. Use method="pcolormesh" to draw each measured time/diameter bin without contour interpolation.

process_parsivel.compute_band_reflectivity(psd, *, bands='all', water_temperature=20.0, permittivity_model='Liebe1991', diameter_widths=None, frequencies=None, minimum_dbz=None)[source]#

Compute intrinsic liquid-water Mie equivalent reflectivity by radar band.

The PSD must have drop-diameter centers in millimetres as columns and concentrations in m^-3 mm^-1. Drops are modeled as homogeneous spheres. Results exclude atmospheric/rain-path attenuation and nonspherical-drop polarization effects.

Save parameters, PSD, and moments to one verified NetCDF file.
