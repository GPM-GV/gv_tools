Examples#

Post-processed MRRPro#

Read an hourly directory into one xarray dataset and save a three-panel time-height display from tcsh:

set WORKSPACE = "$HOME/Desktop/Work/GV_Tools"
set PYTHON = "$HOME/anaconda3/bin/python"
$PYTHON "$WORKSPACE/gv_tools/examples/plot_postprocessed_mrr.py" \
  /Volumes/36TB/MRR/TAMU-CC/reprocessed/nc_files/nc_files_c01_mom/2023/08/22 \
  "$WORKSPACE/MRRPro_TAMUCC_20230822.png"

The example appends the detected product code, producing MRRPro_TAMUCC_20230822_mom.png. Spectral and original products use _spc and _org respectively.

Runnable Python examples are kept in the project-level examples folder.

 1"""Minimal task-oriented GV Tools examples."""
 2
 3import os
 4from pathlib import Path
 5
 6import gv_tools
 7
 8
 9INPUT_DIR = Path("/path/to/input")
10OUTPUT_DIR = Path("/path/to/output")
11FILES = [INPUT_DIR / "PIERS0042_Parsivel_20260810_daily.zip"]
12parsivel = gv_tools.io.read_parsivel(FILES)
13
14gv_tools.correct.validate_product(parsivel)
15gv_tools.io.write_product(parsivel, OUTPUT_DIR, formats=("netcdf",), day="2026-08-10")
16
17
18# Optionally demonstrate content-aware radar ingest. For example, point this
19# variable at a KCRP..._V06 NEXRAD Level-II file before running the script.
20radar_name = os.environ.get("GV_TOOLS_RADAR_FILE")
21if radar_name:
22    radar_path = Path(radar_name).expanduser().resolve()
23    route = gv_tools.io.inspect_radar(radar_path)
24    radar = gv_tools.io.read_radar(radar_path)
25    print(f"Radar route: {route.family} / {route.file_format} / {route.reader}")
26    print(
27        f"Radar dimensions: {radar.nsweeps} sweeps, "
28        f"{radar.nrays} rays, {radar.ngates} gates"
29    )
30    print(f"Radar fields: {sorted(radar.fields)}")
31else:
32    print("Radar example skipped: set GV_TOOLS_RADAR_FILE to one radar file")
