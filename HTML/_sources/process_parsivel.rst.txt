Process Parsivel
================

``process_parsivel`` 1.2.1 is bundled with GV Tools 0.40.0. The bundled copy
supports APU and PIERS archives, location timelines, daily processing,
NetCDF output, radar-band reflectivity, and parameter/DSD plotting. A separate
``process-parsivel`` installation is not required.
