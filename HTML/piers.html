PIERS Tools#

piers_tools 0.9.0 replaces both piers_gauge_tools and process_piers_plus. It includes packet and daily gauge parsing, daily reports, plotting, publishing, standalone-gauge comparisons, PIERS++ day processing, AIO processing, and gauge NetCDF export.

Unified PIERS gauge, platform, and comparison tools.

The public API combines the former piers_gauge_tools daily-report package with the former comp_standalone_gauges range-comparison package. Application code should import from this module or from the documented submodules; the two legacy package names are intentionally not installed.
