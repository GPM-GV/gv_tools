PIERS Tools
===========

``piers_tools`` 0.9.0 replaces both ``piers_gauge_tools`` and
``process_piers_plus``. It includes packet and daily gauge parsing, daily
reports, plotting, publishing, standalone-gauge comparisons, PIERS++ day
processing, AIO processing, and gauge NetCDF export.

.. automodule:: piers_tools
   :members:

Command line programs
---------------------

The unified wheel installs ``piers-gauge-report``, ``piers-compare-gauges``,
``piers-plus-process``, and ``piers-gauge-ingest``.
